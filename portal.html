Benchmarking Briefing

Profile Review · Project Benchmarking (SeekOut). Click through the steps, the decision helper and the practice cards to learn the rules.

I am

L2 view: your L2 rules and tasks are highlighted in purple; everything else is dimmed (hover to read it).

In one sentence

For every field, compare THE FILE SAYS (the SeekOut database) with PUBLIC PROFILE SAYS (LinkedIn data pulled by ZIPLabs). Same information = Match. Different information = Not a match. Truly unclear = Can't decide.

The five most important rules

Step by step

1Before you start
  • Each profile is reserved for you for a limited time, shown top right (e.g. "Reserved for you until 11:05 PM"). Finish it before then, or it goes back to the queue.
  • The top bar shows Today, Checkpoint streak and Accuracy (30 days). Some answers are peer-checked, so accuracy matters more than speed.
  • Use Exit (top right) only when you want to stop working.
2Read the profile header

At the top you see the person's name, job title at company, location, and their headline. Read these first so you know who you are checking. The header is for orientation only: you answer the fields below it.

3LinkedIn: who uses it and when

L1 staff: work on this screen only. Do NOT open LinkedIn as a routine step. Open it only when THE FILE SAYS has data and PUBLIC PROFILE SAYS is empty (still empty after one Refresh). Then check that field only, answer, and return.

  1. Click ↻ Refresh public profile once and wait. If data appears, continue with the normal check.
  2. Still empty: click Open LinkedIn ↗. It opens in a new tab.
  3. Make sure it is the same person: name, photo, location. A different person or a page that won't open = Can't decide.
  4. Find only the field you are checking (e.g. About, current job title).
  5. Compare with THE FILE SAYS: same = Match; different = Not a match; nothing shown for that field = Not a match.
  6. Close the LinkedIn tab and answer on the review screen.

L2 staff: may open LinkedIn on any profile to verify it, and use the "Checked on LinkedIn?" buttons.

  1. Click Open LinkedIn ↗ and confirm it is the same person: name, photo, location and work history.
  2. Back on the review screen, answer "Checked on LinkedIn?": ✓ Public profile matches LinkedIn or ✗ Doesn't match LinkedIn (e.g. a newer job).
  3. Also resolve cases L1 marked Can't decide where LinkedIn would help (out-of-date profiles, changed last names).

If the screen says "It comes back to the queue in a few minutes" after a refresh, move on; the profile returns later.

4Check each field

The dots above the field name show where you are (e.g. FIELD 2 OF 8). The number of fields changes, because the system only asks about fields it has data for.

  1. Read the question.
  2. Compare THE FILE SAYS (left) with PUBLIC PROFILE SAYS (right). Highlighted words show the differences.
  3. Read the grey rule box under the two boxes.
  4. Follow the and apply the .
  5. Choose one answer. You move on automatically; ← Back changes an earlier answer.
5Finish the profile

After the last field the profile is complete and the next one loads. Your Today count goes up by one.

The three answers

✓ MatchThe information is the same, following the rule box and this guide.
✗ Not a matchThe information is really different, or one side is empty and the other is not.
? Can't decideData has no connection to the file (another person or company), or LinkedIn can't be checked when the public box is empty. Use sparingly.

Keyboard: each button shows its key number (1, 2 or 3). Always check the number printed on the button before using the keyboard.

Years calculator

Years = the file's year minus the start year. Months don't count: in a 2026 file, any start in 2018 is 8 years. The public profile's number is already counted this way.

For Years at company use the FIRST role of the latest unbroken stretch at that company, including earlier company names and moves between the parent and a subsidiary. A break, or a job at another organisation in between, restarts the count. The role must show "Present" with no end date.

Job title checker

Every word must be in both boxes, in the same order. Only capital letters, the short forms the rule box lists (for example Snr = Senior, Dev = Developer, Mgr = Manager) and a company name in full or short form (AWS = Amazon Web Services) may differ.
